# Coca-Cola-Interactive-Expandable-3D-Product-Card-
Coca-Cola Interactive Expandable 3D Product Card Designed and developed a modern, highly interactive 3D product showcase card inspired by high-converting e-commerce web components. The project features smooth CSS3 animations, dynamic scale transitions, and a clean UI layout.

Initially, the card displays a glowing brand circle with a centered logo. On hover, the circle seamlessly expands to fill the background while revealing a floating 3D product bottle alongside detailed product descriptions and a call-to-action button.

Key Features & Technical Highlights:

Dynamic Hover Animations: Built using CSS3 transforms (clip-path, rotate, scale) and smooth transition delays.

Responsive Layout: Designed with a fluid CSS Flexbox architecture that adjusts dynamically on hover.

Performance Focused: Written in lightweight, native HTML5 and CSS3 without heavy external animation libraries.

Vector Graphics: Integrated optimized SVG assets to ensure high resolution across all screen sizes.

Tech Stack Used:
HTML5, CSS3 (CSS Variables, Clip-Path, Flexbox), JavaScript
